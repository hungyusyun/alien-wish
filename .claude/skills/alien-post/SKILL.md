# 外星人祈願雞蛋糕 貼文產出

## 我需要先知道的事

使用者沒講清楚就先問（一次問完，不要一題一題擠）：

1. **平台**：IG 貼文 / IG 限動 / LINE 推播
2. **主打**：刀療 / 易經 / 塔羅 / 祈願卡 / 綜合
3. **篇數**：預設 3 篇

<!-- 教學：skill 就是「把你每次都要重講一遍的話，寫死在這裡」。
     這段就是在省掉你每次都要交代的背景。 -->

## 品牌資料

價目、地址、營業時間、語氣規則一律以 `references/brand.md` 為準，**不要自己編**。
要用到時才讀那個檔案。

<!-- 教學：這就是「主檔瘦、細節外掛」的做法。
     brand.md 之後會越長越大（活動、常見問答、客人金句），
     但它平常不佔你的 context，只有真的要寫貼文時才被讀進來。 -->

## 每篇的輸出格式

```
【鉤子】一句話，15 字內，要讓人停下滑動
【內文】80–150 字
【CTA】一句行動呼籲（含地址或 LINE）
【Hashtag】8–12 個，混合大小標籤
【圖卡文字】主標 8 字內 ／ 副標 15 字內
```

## 硬規則

- 一律繁體中文
- 不承諾療效、不用「治癒」「根治」「保證」這類字眼（會被檢舉）
- 每篇都要出現「鹿港」或「天后宮」，本地搜尋才吃得到
- 語氣：溫暖 + 一點外星人的怪，不要心靈雞湯腔

## 產完之後

跑一次檢查：

```bash
python3 .claude/skills/alien-post/scripts/check_post.py <貼文檔案路徑>
```

沒過就自己改到過，不要丟給使用者。
