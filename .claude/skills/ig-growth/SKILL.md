# IG 流量發文

帳號定位：**AI 影片批量製作 × n8n 自動化**，教學／工具分享型。
目標：觸及新觀眾 → 漲粉 → 導向接案與課程。

## 開始前先確認

使用者沒說就一次問完，不要一題一題擠：

1. **主題**（例：用 n8n 自動發 IG、AI 配音工具比較、三分鐘做完一支短影音）
2. **格式**：Reels ／ 輪播 ／ 讓我推薦
3. **則數**：預設 3 則

格式不確定時的判斷：**衝觸及漲粉一律 Reels**；只有在「步驟需要被反覆看、要衝儲存」時才用輪播。
理由與數據見 `references/playbook.md`。

## 輸出格式

完整範例（已通過檢查，照這個格式寫）：`references/example.md`

### 每一則都要給 3 個鉤子變體

這是拿來 A／B 測試的，不是讓使用者挑好看的。三個要走**不同路線**（資訊差／結果數字／反直覺），
不能是同一句話換講法。路線清單見 `references/hooks.md`。

### Reels

```
── 第 N 則 ──
【鉤子 A】（資訊差路線）
【鉤子 B】（結果數字路線）
【鉤子 C】（反直覺路線）

【總長】XX 秒
【分鏡】
 0.0–1.5s ｜畫面：___ ｜字卡：___ ｜口白：___
 1.5–4s   ｜畫面：___ ｜字卡：___ ｜口白：___
 （每格 2–3 秒，不要有超過 4 秒不換畫面的格）
【文案首句】___（必須含主關鍵字，40 字內）
【文案內文】___
【CTA】___
【Hashtag】3–5 個
```

### 輪播

```
── 第 N 則 ──
【鉤子 A／B／C】同上
【P1】主標 12 字內 ／ 副標 20 字內
【P2】痛點或情境
【P3–P7】步驟，一頁一個動作
【P8】總結
【P9】CTA
【文案首句／內文／CTA／Hashtag】同上
```

頁數 6–10 頁。

## 硬規則

這幾條是演算法層面的，不是風格偏好，**不要為了文案順暢而違反**：

- **Hashtag 只放 3–5 個。** 放滿 30 個會被降權
- **主關鍵字必須出現在文案第一句**，而且要自然。留言區的關鍵字不被索引，寫在那裡等於沒寫
- **關鍵字也要出現在畫面字卡上**（IG 會讀畫面文字）
- **鉤子在 1.5 秒內出現。** 不要開場問候、不要自我介紹、不要「大家好」
- **Reels 長度看題型**：鉤子型 7–15 秒、技巧清單 15–30 秒、完整教學 30–60 秒。不確定就選短的
- **CTA 要能產生「私訊分享」或「留言」**，不要只寫「追蹤我」。分享數是目前最強的觸及訊號
- 一律繁體中文，台灣用語（影片不是視頻、按讚不是點贊、螢幕不是屏幕）
- 不要 emoji 開頭、不要整排 emoji 分隔線

## 產完要做的事

1. 把這批貼文存成 `.claude/skills/ig-growth/posts/YYYY-MM-DD-主題.md`
2. 跑檢查，沒過就自己改到過，**不要把沒過的東西丟給使用者**：

```bash
python3 .claude/skills/ig-growth/scripts/check_post.py <檔案路徑> --keyword <主關鍵字>
```

3. 在 `posts/log.md` 每則補一行，數據欄先留空

數據要等發文後才有。累積 10 則以上再回頭看哪條鉤子路線有效 ——
沒有這個記錄，所謂測試就只是亂槍打鳥。
